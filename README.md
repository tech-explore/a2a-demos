# A2A Protocol demos

**A2A protocol** is one of the prominent protocols emerging in the Agent AI ecosystem. Rightly so it is now a key project under Agentic AI Foundation umbrella. "Agents" has become a very common term in technology and even in business domain. As uptake of agent systems increases drastically and replacing many human tasks, naturally there is a need for agents to interact as humans interact. A2A protocol is one of the first steps in that direction. 

This is an attempt to demonstrate how A2A protocol can be utilized for agent interaction. First demo is focused on travel industry. But the intent is to create more demos in furture to highlight different aspects of A2A protocol and to highlight applicability of A2A in different business domains.

As of now this demo focuses on a simple usage of A2A and not on agents. Hence usage of MCP and LLM is out of scope of these demos. For better understanding of A2A and the demo, following documentation is provided:
